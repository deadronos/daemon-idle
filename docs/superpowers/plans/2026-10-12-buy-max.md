# Buy-Max Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an earned "buy max" toggle that buys the maximum affordable units of a spawn tier in one click, bounded by both `cycles` and RAM.

**Architecture:** Pure `maxAffordable` + gated `spawnMax` in `src/sim.ts`; one `bulk-buy` milestone row in `src/config/milestones.ts` granting #17's `buy-max` unlock; a persisted `buyMax` toggle and a spawn-panel checkbox in `src/main.ts`; sanitizing + a staged migration in `src/persistence.ts`.

**Tech Stack:** TypeScript (strict) + Vite/Vite+ (`vp`), Vitest via `vite-plus/test`, `Decimal` via `src/bignum.ts`.

**Spec:** [`docs/superpowers/specs/2026-10-12-buy-max-design.md`](../specs/2026-10-12-buy-max-design.md)

## Global Constraints

- TypeScript strict; `noUnusedLocals`/`noUnusedParameters` on.
- Unbounded values use `Decimal` from `src/bignum.ts`.
- Every mutating sim action returns `boolean` (`false` = refused).
- New persistent fields get a `newGame()` default; saves merge over defaults (additive-safe).
- `SAVE_VERSION` bumps (3 → 4 on this stack) with a **staged** step (`if (from < 4) …`); never a single `< SAVE_VERSION` check.
- `sim.ts` must not import `persistence.ts` (cycle) — `MAX_SANE_COUNT` is not used.
- This branch stacks on `feat/17-milestones`; RAM uses `s.ramCap` (see the spec's consolidation note).
- `npm run check` (typecheck + lint + test) must pass.

## Review Focus

Failure modes the spec implies but a single task's test might miss — each gets a test in its owning task:

1. **Exactness:** `maxAffordable` must equal a brute-force `spawn` loop (no off-by-one from Decimal logs) (Task 1).
2. **Overspend:** after `spawnMax`, `cycles >= 0` and `ramUsed <= s.ramCap` (Task 2).
3. **Lock bypass:** `spawnMax` must refuse while `buy-max` is locked, even called directly (Task 2).
4. **Corrupt toggle:** a non-boolean `buyMax` in a save coerces to a boolean without throwing (Task 3).
5. **Zero:** an unaffordable / RAM-less tier returns `k = 0` and `spawnMax` returns `false` (Tasks 1–2).

```ts
/** Largest number of units of tier `i` buyable now, bounded by `cycles` and RAM. Pure. */
export function maxAffordable(s: GameState, i: number): number {
  const def = TIERS[i];
  if (!def) return 0;
  const room = Math.floor((s.ramCap - ramUsed(s)) / def.ram);
  if (room <= 0) return 0;
  const next = tierCost(s, i); // cost of the next unit
  const growth = def.costGrowth;
  let k = 0;
  if (s.cycles.gt(0)) {
    // solve next * (growth^k - 1) / (growth - 1) <= cycles  ->  k
    const ratio = s.cycles
      .mul(growth - 1)
      .div(next)
      .add(1);
    k = Math.floor(ratio.ln().div(Math.log(growth)).toNumber());
  }
  if (!Number.isFinite(k) || k < 0) k = 0;
  k = Math.min(k, room);
  const total = (n: number) => next.mul(d(growth).pow(n).sub(1)).div(growth - 1);
  while (k > 0 && total(k).gt(s.cycles)) k--; // absorb Decimal rounding
  while (k + 1 <= room && total(k + 1).lte(s.cycles)) k++;
  return k;
}
```

> If `Decimal` has no `.ln()`, use `.log10()` and divide by `Math.log10(growth)`.

  ```ts
  export function spawnMax(s: GameState, i: number): boolean {
    if (!hasUnlock(s, UNLOCK.buyMax)) return false;
    const k = maxAffordable(s, i);
    if (k <= 0) return false;
    const growth = TIERS[i].costGrowth;
    const total = tierCost(s, i)
      .mul(d(growth).pow(k).sub(1))
      .div(growth - 1);
    s.cycles = s.cycles.sub(total);
    s.counts[i] += k;
    log(s, `spawn x${k}: ${TIERS[i].name}`);
    return true;
  }
  ```
